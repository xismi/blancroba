# Blanc Roba

Web profesional multidioma para la tienda **Blanc Roba** de Alaior, Menorca.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
```

El resultado desplegable se genera en `dist/`.

## Características

- Español, catalán e inglés
- Diseño adaptable a móvil y escritorio
- Información real de horario y ubicación
- Llamada directa desde móvil
- Enlace a Google Maps
- Instagram
- Asesor de estilo guiado, sin chatbot conversacional
